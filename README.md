# Task Engine

Task Engine is a simple and responsive to-do list application built with React and Vite. I created this project while learning React to practice component-based development, state management, user interactions, and browser storage.

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed or active
* Delete tasks
* Filter tasks by All, Active, and Completed
* View total, active, and completed task counts
* Dark and light modes
* Theme preference saved in local storage
* Tasks saved in local storage
* Add tasks using the Enter key
* Responsive design for desktop and mobile devices
* Empty-state feedback when no tasks are available

## Technologies Used

* React
* JavaScript (ES6+)
* Vite
* CSS
* Material UI Icons
* Browser Local Storage

## What I Practiced

This project helped me practice:

* Building reusable React components
* Managing state with `useState`
* Using `useEffect` for side effects
* Passing data and functions through props
* Rendering lists and filtering data
* Handling user events
* Persisting data with `localStorage`
* Implementing light and dark themes
* Creating responsive layouts with CSS
* Basic accessibility practices

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Illy-2024/react-todo-app.git
```

Navigate to the project directory:

```bash
cd todo-app
```

Install the dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Then open the local URL displayed by Vite in your browser.

## Production Build

To create a production build:

```bash
pnpm build
```
